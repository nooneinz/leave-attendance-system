# Employee Leave & Attendance System — نظام الإجازات والحضور

نظام موارد بشرية لشركات سلطنة عُمان: حضور وانصراف مرتبطان بأجهزة البصمة، طلبات إجازة بموافقات حسب الصلاحية، أرصدة تُحسب تلقائياً، ومهام مجدولة تغلق الأيام والتقارير الدورية، مع وكيلين بالذكاء الاصطناعي. التوقيت: مسقط (GMT+4)، والعملة: الريال العماني.

## المشكلة
صعوبة تتبع الحضور والانصراف، وأخطاء احتساب أرصدة الإجازات يدوياً، وتداخل طلبات الإجازة مع جداول العمل في الأقسام.

## ما الذي يقدّمه
- **الحضور:** بصمة من الويب (بوقت الخادم)، أو من جهاز بصمة عبر `POST /api/devices/punch` بمفتاح لكل جهاز، أو استيراد CSV من الجهاز. يُحسب التأخير والانصراف المبكر وساعات العمل.
- **الإجازات:** ست أنواع قابلة للتعديل (سنوية، مرضية، وضع، أبوة، حج، بدون راتب)، تُحتسب أيام العمل أو الأيام التقويمية حسب النوع، وتُستثنى الإجازة الأسبوعية (الجمعة والسبت افتراضياً) والعطل الرسمية.
- **الأرصدة:** دفتر قيود (Ledger) لا يُعدَّل؛ الاستحقاق الشهري للسنوية (30 ÷ 12) لا يتكرر أبداً، والتسويات اليدوية مسبّبة ومسجّلة.
- **الموافقات (JWT + أدوار):** موظف ← مدير القسم ← الموارد البشرية؛ مدير القسم ← الموارد البشرية؛ الموارد البشرية ← المشرف. لا أحد يوافق على طلبه.
- **المهام المجدولة (APScheduler، توقيت مسقط):** إغلاق الحضور يومياً مع تعويض الأيام الفائتة، استحقاق الإجازة شهرياً، تجديد الحصص سنوياً، وتقرير الغياب الشهري. كلها قابلة للتشغيل اليدوي وتُسجَّل نتيجتها.
- **سجل تدقيق** مرتبط بتجزئة SHA-256 يكشف أي تلاعب، وتنبيهات داخلية، وتقويم فريق، ورسوم بيانية (Recharts).

## وكلاء الذكاء الاصطناعي
| الوكيل | المهمة |
|---|---|
| **وكيل الجدول والتغطية** | عند تقديم الطلب يفحص تغطية القسم يوماً بيوم مقابل الحد الأدنى للقسم، ويتحقق من الرصيد والتداخل، ويقترح أقرب موعد بديل بتغطية كافية، ويوافق تلقائياً على الإجازات السنوية القصيرة المستوفية للشروط (قابلة للإيقاف). |
| **وكيل تحليل أنماط الغياب** | يحلل التأخير والغياب بدون إذن والأيام الملاصقة للإجازة الأسبوعية وعدم البصمة عند الانصراف، ويحسب درجة خطورة لكل موظف وتوقع الغياب للشهر القادم واتجاه التصاعد، ويقدّر الخصم بالريال العماني، ويصدر تقريراً شهرياً تلقائياً. |

المنطق الأساسي قواعد حسابية صارمة تعمل دائماً وبدون مفتاح. عند ضبط `ANTHROPIC_API_KEY` يكتب Claude الشرح النصي للتوصيات والتقارير فقط، ولا يغيّر الأرقام.

## ملاحظات عُمانية
- القيم الافتراضية: دوام 08:00–16:00، سماحية تأخير 15 دقيقة، عطلة الجمعة والسبت، حصص (30 سنوية، 10 مرضية، 98 وضع، 7 أبوة، 15 حج). عدّلها من **الإدارة ← سياسة الدوام والإجازات** بما يوافق قانون العمل وسياسة شركتك.
- العطل ذات التاريخ الهجري (الأعياد، رأس السنة الهجرية، المولد النبوي) تُضاف يدوياً عند صدور التواريخ.

## التقنيات
FastAPI · SQLAlchemy · PostgreSQL (SQLite محلياً) · APScheduler · React + Vite · Tailwind CSS · Recharts · JWT · Docker.

## التشغيل المحلي
```bash
cd frontend && npm install && npm run build
cd ../backend
python -m venv .venv && .venv/Scripts/activate      # Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
cp ../.env.example .env                              # عدّل ADMIN_PASSWORD و JWT_SECRET
uvicorn app.main:app --port 8001
```
افتح http://127.0.0.1:8001 وسجّل الدخول بحساب المشرف، ثم أضف الأقسام والموظفين من **الإدارة**.

## التشغيل بـ Docker
```bash
cp .env.example .env   # أضف أيضاً DB_PASSWORD
docker compose up --build
```

## ربط جهاز البصمة
```bash
curl -X POST http://HOST/api/devices/punch -H "X-Device-Key: <مفتاح الجهاز>" \
     -H "Content-Type: application/json" -d '{"employee_no":"E1001","timestamp":"2026-10-05T07:58:00"}'
```

## الاختبارات
```bash
cd backend && pytest
```
